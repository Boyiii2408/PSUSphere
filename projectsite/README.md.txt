# PSUSphere

## Project Description
PSUSphere is a web-based Django application designed to manage student organizations within the university.  
The system allows administrators to organize colleges, academic programs, students, and student organizations, as well as track organization memberships efficiently using Django’s built-in admin interface.

---

## Features
- Manage Colleges and Academic Programs
- Manage Student Organizations
- Register Students and their Programs
- Track Student Organization Memberships
- Django Admin Dashboard for easy data management
- Automated fake data generation using Faker

---

## Technologies Used
- Python
- Django
- SQLite
- Faker
- HTML / CSS (Django Admin)
